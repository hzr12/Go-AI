### P2.6 明细（规则引擎 → OpenSpiel 语义，单一规则集；执行拆为 P2.6a / P2.6b）

**a. 动作空间契约**（`go_rules.py`）
- `PASS = bs*bs`（沿用现有 `n_actions = bs*bs+1` 约定）+ `GoBoard.PASS` / `num_actions()` /
  `action_to_coord()` / `coord_to_action()` / `action_to_string()`（SGF 记法：pass / 坐标）/ `string_to_action()`；
- `legal_actions() -> list[int]`（升序、含 PASS）、`is_legal(action) -> bool`；
- `get_legal_moves()` 的**返回形状与缓存契约不变**（8 类消费者与 `test_mcts.py:68` 零改动即受益），语义变严。

**b. 合法性四条**（取代现有 `get_legal_moves:102-141`）
1. 空点；2. **禁自杀**；3. 超级劫统一裁决（**删除** `ko_point` 单独判罚，`ko_point` 降级为只读派生量）；
4. **位置超级劫（PSK）**：落子后若「棋盘+行棋方」哈希命中历史集合 → 非法。
- 自杀判定**不得**沿用 `get_legal_moves:124-134` 那种「原地改 `self.board` 再清 0」的模拟法（污染缓存/并发假设），
  改用棋块信息判定：任一邻接敌块气数==1 → 合法；否则落点所在（合并后）己方连通块总气 ≥1 → 合法。
- **重复局面是「非法手」不是终局条件**（TT 规则 6/8，v3.1 依一手来源订正）：终局 = 两次连续 pass；
  `is_terminal()` **不得**纳入重复判定。
- 哈希：Zobrist 表用**固定种子**在模块加载时预生成；`play` 追加、`undo` 回退、`clone` 深拷贝、`reset` 清空；
  `is_repetition()` 暴露当前局面是否重复（**仅供自检，绝不可当合法性入口**）；历史集合**每次落子后**插入当前
  **position-only 键**，初始空局面也在内；pass 在 position-only 键下与当前局面相同 → **pass 必须豁免 PSK 判定**，
  否则所有 pass 都会被判非法（豁免逻辑要落在第一个引入 PASS 动作的那一层，即动作空间 API）；
  **重复判定的键只含棋盘染色，不含行棋方**（PSK，见 D14 v3.1；唯一正确入口 `position_hash_after_move(mv)`，

### P3-C（v3 新增，排期在 3.0 之后）RL 策略更新 = PPO + KL 散度约束

> 动机：3.0 之后 π 目标**就是网络自己的（掩码）分布**，再对它做 MSE 回归等于让网络拟合自己——梯度近乎无效，
> 且训练侧 `softmax(policy)` 用的是**全动作** logits、与自对弈侧的**掩码**分布口径不一致。PPO 用「行为分布 + 优势」更新，
> 并把 mask 带到训练侧，一次修掉这两条。

**a. 行为数据（`self_play_game` 重写后的版本 + `_process_game_data:954-973`）**
- 每步返回值从 5 元组扩为 **7 元组**：`(planes, action, logp_old, to_play, mc, root_value, mask)`
  —— `vt`（π 目标）**不再需要**（PPO 不做回归），新增**采样动作索引**、**采样时 log-prob**、**合法动作掩码**；
- `logp_old` = 采样时**温度作用后**的掩码分布 log-prob（D13③：保留温度且正确记账，不引入采样偏置）；
- `mask` = 长度 `bs*bs+1` 的 bool 掩码（自对弈侧现成，`get_legal_moves()`）；
  训练侧无法从 planes 复原掩码（掩码不是特征通道），故必须随样本入 buffer；
  体积代价：19 路 ≈ 362 B/样本，对比 planes（12×19×19 fp32 ≈ 17 KB）约 2%，可接受；
- `to_play` / `mc` / `root_value` 语义不变 → **`compute_td_target` 契约与 `test_td_learning` 零改动**；
- buffer 行变为 `(planes, action, logp_old, z, mask)`（`z` 仍由 `compute_td_target` 产出）；
- buffer 每轮清空的现有语义**必须保留**（`logp_old` 一旦跨策略版本复用即失效；D13⑦）。

**b. 增强一致性（`augment8:276`）**
- 8 路对称增强要同时置换策略域对象：**动作索引**与**合法掩码**必须与 visit 目标用**同一套 D4 置换**；
- 实现上抽一个「置换矩阵构造器」供三处复用（visit 目标分布、动作索引、掩码），单一真相源；
- 现有 `augment8(plane, target, n)` 签名与行为**保持兼容**（`test_td_learning.py:215` 的 legacy 对照不得回归），
  动作/掩码走新增可选参数；
- `async_pipeline.py:385` 同一调用点同步。

**c. `train_epochs`（`:455-472`）策略侧**
- `logits` → 按 `mask` 置 `-inf` → `logp_new = log_softmax(logits)`；
- `r = exp(logp_new - logp_old)`；`A = (z - v_old)`（`v_old` = 行内 `root_value`），**按 minibatch 标准化**
  （std 夹紧防 0 除）；
- `L_pi = -min(r·A, clip(r, 1-ε, 1+ε)·A) - β·KL_k1`，其中 `KL_k1 = logp_old - logp_new`（**停止梯度**的 old 侧为常量）；
- **value 侧本任务不动**（保持现状，其已知语义错归 P3-D）；
- β 自适应：每次更新后按 `β ← clamp(β·exp((KL_obs - kl_target)/kl_target), β_min, β_max)` 更新（上下夹紧常量写死）；
- 信任域硬约束：running-KL > `2*kl_target` 时**提前中止本轮剩余 minibatch**（并记日志说明被截断）；

- 日志新增 `kl` / `clip_frac` / `entropy`（旧键一律不动；`test_swanlab_logging` 不得回归）。
