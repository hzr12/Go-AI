## 10. 执行顺序、验收与风险

```
Step 0(基线+本文件) → P1 → P2 → P4(4.12=4.15a, 4.13=4.16) → P5(云端, 5.7=回填4.15b) → P3(3.0→3.6)
```

- **每阶段验收**：`python -m pytest tests -q && bash -n shell/*.sh`
- **run.txt 双编辑点**：P4.12（SFT 节）与 P3.0-e（RL 节）按序执行，`test_run_txt_sync` 自动把关
  （表头计数、双向选项、⓪ lr 平方根律、方案 B/C 锚点、⓪ RL 默认值）
- **执行方式**：子代理逐任务（推荐）或本会话内联批量执行（待选定）
