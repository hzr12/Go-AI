#   LR 与 epoch 也各自独立。

# ================= 段 3：RL（自对弈，**仅单卡 910A**） =================
# ⚠ **硬件只支持单卡 910A，没有多卡 RL 脚本。** shell/ 里只有 train_rl_npu_1card.sh。
#    SFT 是 2/4 卡而 RL 是 1 卡，**不能负载同时**（同一批硬件，不可能两件事同时占满）
#    selfplay_train.py 的 `--ddp 1` 默认 0 + torchrun 加速在多卡上**未验证**，

# ⚠ **RL 是 CPU 瓶颈**：CPU 预算 = parallel_games × mcts_threads。24 是实测甜点

# ⚠ --sims 48 是**强烈建议**：默认 400 在 19 路卡上近似白跑，必须显式 --sims 和调小 --parallel-games
#   过 MCTS 门槛后有效率下降，慢棋会直接把吞吐拖垮
# ⚠ --model 要指**真实存在**的 checkpoint 名字：train_rl_npu_1card.sh 里写的是
